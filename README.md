# Computer Health Monitor

A Python program that displays information about a computer's health.

## What it does

- Checks disk usage
- Checks CPU usage
- Checks available disk space
- Shows CPU information
- Shows memory information
- Shows boot time
- Shows disk information
- Shows network information
- Shows network interfaces
- Shows network I/O statistics

## Requirements

This program uses Python and psutil.

Install psutil with:

pip install psutil

## How to Run

Run the program with:

python Computer_Health.py
